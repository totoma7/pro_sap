심화 8

AEO & 반도체 공정 통합 맵

수출입 안전관리 우수업체(AEO)를 추가하고, 지금까지 본 반도체 구매 업무들이 Fab 공정 흐름 위에서 어떻게 한 줄로 연결되는지 한 장으로 도식화한다. 반도체 시리즈의 허브.

1. AEO — 신뢰받는 무역업체 인증

반도체는 자재·장비·완제품이 끊임없이 국경을 넘는 산업이다. 통관이 막히면 Fab도 막힌다. AEO(Authorized Economic Operator, 수출입 안전관리 우수업체)는 관세 당국이 "이 회사는 믿을 수 있다"고 인증해 통관을 우대하는 제도다.

AEO가 주는 것 (혜택)

  • 통관 신속 — 검사 비율 축소, 우선 처리
  • 담보 생략·관세 납부 유예
  • 상호인정협정(MRA) — 상대국에서도 우대
  • 공급망 차질 시 우선 복구 대상

AEO가 요구하는 것 (의무)

  • 법규 준수 — 관세·수출입 위반 이력 관리
  • 내부 통제 — 거래·재고·HS코드 정확성
  • 공급망 보안 — 물류·시설·인원·정보 보안
  • 거래처(협력사)까지 보안 수준 확장

AEO vs GTS(수출통제) — 헷갈리지 말 것

구분GTS 수출통제 (심화 5)AEO
묻는 질문"이걸 수출해도 되나?""우리는 믿을 만한 무역업체인가?"

둘은 함께 작동한다 GTS가 "이 거래가 합법인가"를 거래마다 막아주고, AEO는 "그렇게 통제를 잘하는 회사"라는 자격을 부여해 합법 거래를 빠르게 흘려준다. AEO 인증을 유지하려면 GTS 같은 수출통제 내부 통제가 잘 돌아가야 하므로, 둘은 원인-결과 관계다.

물류 보안운송사·보세창고 보안 인증 확인 — 협력사 등록 심사 항목
공급망 AEO 연쇄 내가 AEO를 유지하려면 협력사·물류사도 보안 수준을 맞춰야 한다. 그래서 AEO는 ESG(심화 7)와 똑같이 "고객 요구 → 우리 → 협력사"로 전가되는 공급망 항목이 된다 — 협력사 평가·등록 심사에 녹여 넣는 것이 정석이다.

4. 한 줄 결론

반도체 구매 = 공정을 따라 흐르는 사슬 + 두 개의 피드백 루프 계획(MRP) → 소싱 → 구매 → 전공정 → 후공정(OSAT) → 수출입(GTS·AEO) → 매각의 직선 위에, 사용량→계획과 실적→평가 두 순환이 돈다. AEO와 ESG는 이 사슬 전체를 감싸는 공급망 자격 레이어로, 협력사 평가·등록 심사를 통해 사슬 곳곳에 스며든다.
