2. IDoc — 비동기 문서 교환의 표준

IDoc(Intermediate Document)은 "전자 문서 봉투"다. PO·송장 같은 문서를 정해진 구조에 담아 큐로 주고받는다. 비동기이므로 상대 시스템이 죽어 있어도 일단 쌓이고, 나중에 재처리할 수 있다.

구조

3. RFC / BAPI — 동기 함수 호출

BAPI는 SAP이 공식 보장하는 비즈니스 함수다. 외부에서 RFC 프로토콜로 호출하면 즉시 결과(성공/오류 메시지)를 받는다. "지금 당장 PO 번호가 필요한" 화면 연동에 쓴다.

BAPI용도
BAPI_PR_CREATE구매요청(PR) 생성 — 포털 요청 → SAP PR
BAPI_PO_CREATE1구매오더(PO) 생성 — 포털 발주 → SAP PO
BAPI_PO_CHANGEPO 변경
BAPI_GOODSMVT_CREATE입고/출고 등 자재 이동 생성
BAPI_INCOMINGINVOICE_CREATE송장 생성 (MIRO에 해당)
실무 포인트 두 가지 ① BAPI는 호출 후 BAPI_TRANSACTION_COMMIT을 명시 호출해야 저장된다. ② 표준 BAPI로 부족하면 Z-RFC(커스텀 함수)를 만들어 쓰는데, 국내 구매포털 연계는 Z-RFC 비중이 상당히 높다.

4. OData API — S/4 시대의 표준

  • REST 기반 HTTP API. S/4HANA가 표준 제공 — 예: API_PURCHASEORDER_PROCESS_SRV (PO CRUD)
  • 카탈로그는 api.sap.com (SAP Business Accelerator Hub)에서 검색
  • JSON으로 주고받아 웹 개발자 친화적. 클라우드 SaaS(Coupa 등)와의 연계 기본값
  • 인증: Basic/OAuth + 통신 사용자(Communication Arrangement) 설정
